# Clinical Data Management SOP

## 1. Purpose
This procedure defines how clinical trial data is collected, validated and locked for analysis.

## 2. Roles
- The Data Manager owns the data validation plan.
- Site coordinators enter data into the EDC system within 5 business days of a patient visit.
- The Medical Monitor reviews serious adverse events within 24 hours.

## 3. Data Validation

### 3.1 Edit Checks
Edit checks must run automatically on every form when it is saved. Values outside the allowed range must be flagged immediately.

### 3.2 Query Management
Data queries must be answered by the site within 3 business days. Unanswered queries are escalated to the Clinical Research Associate.

## 4. Database Lock
The database can be locked only after all queries are closed and the Principal Investigator has signed off.

Contact the data team at dm-team@example.com or 9876543210 for lock requests.
